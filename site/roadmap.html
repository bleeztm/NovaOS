Roadmap

v0.1 — Bootloader ✅

Dual BIOS+UEFI boot, unified BootInfo, kernel entry. Done and QEMU-verified.

v0.2 — Emergency shell ✅

VGA/framebuffer console, 13 commands, serial mirror, FAT ls. Done.

v0.3 — GUI ✅

Compositor, window manager, taskbar, 4 apps, themes. Done (VRAM-verified).

v0.4 — Filesystem write + processes

FAT12/32 write path, file creation in editor, cooperative multitasking, ELF-ish app loading via syscalls.

v0.5 — Networking idea

NE2000/rtl8139 polling driver, ARP + ICMP ping, tiny HTTP status page served from the kernel.
