Install guide

QEMU (recommended)

git clone https://github.com/bleeztm/NovaOS.git
cd NovaOS
make run-bios        # Linux / WSL / MSYS2
build.bat run-bios   # Windows cmd

Needs nasm, qemu-system-x86_64, python3. Serial log shows every boot stage; press F8 for the shell.

# UEFI path (needs OVMF firmware)
OVMF=/usr/share/OVMF/OVMF_CODE.fd make run-uefi
# Windows: set OVMF=C:\path\to\OVMF_CODE.fd & build.bat run-uefi

Real hardware (USB stick)

  1. Build build/floppy.img (BIOS/CSM) or build/esp.img (UEFI).
  2. Flash with Rufus (DD mode) or balenaEtcher.
  3. Boot the stick. For UEFI: disable Secure Boot (our loader is unsigned).
  4. No display? The shell mirrors everything to COM1 serial — capture with a USB-serial adapter at 38400 8N1.

Tested matrix: QEMU BIOS (SeaBIOS + std VGA) and QEMU UEFI (OVMF + GOP). Real-hardware reports welcome as GitHub issues.

BIOS vs UEFI

BIOS pathUEFI path
Imagefloppy.img (FAT12)esp.img (FAT32 ESP)
Alsonovaos-grub.iso via GRUB multiboot (make iso-grub on Linux/WSL, run with make run-grub)
LoaderMBR + stage2, VBE framebufferEFI/BOOT/BOOTX64.EFI, GOP
Kernel fileKERNEL.BIN (floppy root)KERNEL.BIN (ESP root)
Firmware needsCSM / legacy bootSecure Boot off

Both hand the same BootInfo struct to the same kernel — see docs/BOOT.md.
