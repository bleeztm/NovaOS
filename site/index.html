NovaOS

A hobby operating system written in pure x86 NASM assembly. Dual BIOS + UEFI boot, one 64-bit kernel, GUI desktop, emergency shell.

Download ISO (BIOS/UEFI) GitHub repo
  • 512-byte MBR + stage2 → long mode, VBE framebuffer
  • Pure-ASM UEFI app: GOP, memory map, ExitBootServices
  • Verified in QEMU on both paths — serial logs + VRAM dumps

Features

Dual boot

BIOS (MBR → protected → long mode, VBE) and UEFI (GOP, direct ESP load) converge on one unified BootInfo ABI.

GUI desktop

Framebuffer compositor, draggable windows with title bars, taskbar + start menu, mouse cursor, 8×16 font, light/dark themes.

Emergency shell

Failsafe console (F8 / Ctrl+Alt+T): help mem peek poke ls cat fbinfo gui-restart reboot shutdown halt. Try it below.

Real drivers

GDT/IDT/paging, PIT + RTC, PS/2 keyboard + mouse, ATA PIO, COM1 serial log, PC speaker, int 0x80 syscalls.

Boot it yourself

git clone https://github.com/bleeztm/NovaOS.git
cd NovaOS
# Windows:  build.bat run-bios      (or run-uefi with OVMF set)
# Linux:    make run-bios           (or OVMF=/usr/share/OVMF/OVMF_CODE.fd make run-uefi)

Full guide: Install on QEMU + real hardware. Spec: docs/.
